结构性瓶颈（讲解 P6 的重点）：速度环输出只作为"倾角修正"叠加到目标角，并被 N = MAX_SPEED_ANGLE (0.8°) 硬限幅。修正一旦饱和，"误差再大也只能给 0.8°"， 于是系统在静摩擦下只有两种命运：粘住（稳态≈0） 或 一直加速（跑飞） —— 这就是"只能点动、不能巡航"的代码级原因，也是 2026-11-19 之后所有实验的根源。
