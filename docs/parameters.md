> **两层，别混**：
> 1. **编译期默认值**（`main.cpp` 里的初值）：只在闪存无有效记录时生效，也就是擦除后首次启动。

## 配置口径

1. **上电先 `?` 看 O**：O 会随装配/上电漂移（本次 4.24 ↔ 2.99），每次上电用 `ble_find_o.py` 重测。
2. **改细分必须重标** L/S/B/H/R：这些是 STEP 频率域参数，换细分后不沿用旧值。
3. **N 不要放松**：N=2.0 是已证实的翻车原因；要更大倾角先查是不是增益/粘滞的问题。
4. **I 保持 0**：静摩擦系统里积分会变成极限环。
5. **SP 极性反直觉**：`SP>0` = 后退，`SP<0` = 前进。

## 已否证（别再重推）

| 做法 | 错在哪 |
| --- | --- |
| 加 I 消稳态误差 | 静摩擦下成极限环，稳态速度反向 |
| N 越大越有力 | N=2.0 直接翻车 |
| 增益越大越好 | SV(=K)≥0.20 猛冲撞翻 |
| 地面坡度是全部原因 | 同桌面仅重启，θ* 从 4.24 跳到 2.99 |
| `speedKp` 无在线旋钮 | 错，`K` 一直是它 |

## 源码 vs 实车（重要）

`main.cpp` 里 `MAX_TARGET_FORWARD_SPEED` 已改为 **30.0f**（未提交），但实车跑的是烧录版 **8.0f**。
**下次烧录会改变量程**——这是"源码 ≠ 正在跑的东西"的典型陷阱。
