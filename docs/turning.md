# 固定倾角前后控制与差速转向

更新：2026-10-30，Asia/Shanghai。当前源码采用 MOVE=5 固定倾角按住控制，尚未烧录或通过实车移动验收。最新位置倾角版记录已确认0.50°生效，但6次任务只有1次到位，见[修改依据](validation/analysis/fixed-angle-request-20261030-152627/report.md)。

## 操作

烧录对应固件并重启面板，连接、收到实时遥测后启用遥控。按住“前进”请求相对平衡角O +2°，按住“后退”请求O −2°，松开则平滑回到O。需要时使用前后反向选项匹配实际轮向。倾角固定为2°，界面只读，不再使用旧位置P/倾角上限输入框。

例如O=4°时，两个目标分别为6°和2°。移动期间速度环、驻车位置环不叠加目标角，直立PD继续控制STEP；大姿态误差保护仍优先。遥控不会改写O，不要在运动中同时修改平衡角。

左右转仍按住操作，默认150Hz差速，可调5～300Hz，保留方向反转。停止按钮撤销两轴请求。松开前后按钮只撤销前后倾角，正在按住的转向可继续。

## 平滑开始、释放与反向

手动倾角在400Hz更新。静止起步采用三次平滑曲线，起止变化率为0，最大变化率2°/s、最大变化率的变化4°/s²。从0到±2°约1.73秒；在+2°稳态切换到−2°约3秒。中途释放或反向时，先按4°/s²将当前倾角变化率减至0，再平滑走向新目标，避免参考角或变化率突变。

进入遥控时从当前实际目标角相对O的偏移开始衔接，要求偏移不超过±2°。松开/超时后回到O，再用1秒平滑恢复原速度环对目标角的修正。该1秒限制的是速度环混合权重，手动轨迹的2°/s、4°/s²边界不等于整个闭环目标在所有保护和调参条件下均有相同界限。

固定倾角没有速度闭环约束，长按可能持续加速。回到O也不代表车辆机械瞬间停止。首轮以短按观察方向、角度与制动，不能将参考平滑当作不会倾倒的保证。

## 控制与保护

- 进入时IMU正常、姿态偏离O≤5°，当前目标偏移在±2°内。请求只接受0和±2°。
- 移动及倾角回零期间强制速度积分为0，暂停速度/驻车角度修正。驻车目标在移动、回零及随后1秒速度环恢复期间，以400Hz跟随当前位置，位置误差与位置速度请求保持0，同时清空旧的位置速度斜坡。整个交接完成后锁定最新位置为驻车点，累计编码器坐标始终连续。
- 面板每100ms维持当前请求。固件超过350ms没有刷新就平滑回零；失焦、关闭、断线或1.5秒无遥测会撤销面板请求。
- 偏离O≥10°、IMU或原停机保护触发时立即清除手动请求，保护优先于斜坡。故障后需要先收到零命令再接受新动作。
- 原P/D/O/K/I/N默认配置、speedLoopDirection=-1、电机极性、细分及L/S/B/H保持原值。大角度时原外环权限会缩小，不能把此时的目标衰减解释为±2°请求未发送。

## 协议与遥测

能力标识：`TURN=2 MOVE=5 SMOOTH=1 TILTMAX=2.00`。新面板仅对该版本启用前后操作，旧MOVE=3/4固件的前后按钮禁用。

`^ 差速Hz,相对倾角°`同时更新两轴，例`^ 0,2`、`^ 0,-2`、`^ 0,0`。整帧校验通过才改动请求。旧`@`帧仅接受两轴均为0，旧`~`位置帧拒绝非零目标；旧配置解析和诊断字段保留兼容，不参与新前后操作。

遥测为74个数值项，保留此前71项的索引，并在末尾新增：

| 字段 | 含义 |
| --- | --- |
| manualAngleRate1000 | 手动目标角变化率×1000，°/s |
| manualAnglePhase | 0空闲、1平滑走向目标、2先减速 |
| manualResume1000 | 正常速度环混合权重×1000 |

manualControlMode=5，manualReq1000为相对O请求×1000，manualApplied1000为平滑后偏移×1000，target100为最终目标角×100。旧jog字段不表示新固定角轨迹。CSV兼容49/56/57/63/65/71/74项，旧版本缺失列留空，遥测仍为2Hz。
