# 前后速度闭环与差速转向

更新：2026-11-06，Asia/Shanghai。前后运动已由「固定 2° 开环倾角」改为「速度档位 → 速度闭环倾角」，见
[改造说明](validation/analysis/20261105-fwdback-motion/report.md)。尚未烧录实车验证。

## 操作

烧录对应固件并重启面板，连接、收到实时遥测后启用遥控。按住“前进/后退”给出**速度档位**（0.5～2.0，默认 2.0），
车端按 `档位/2 × 10 counts/50ms` 换算成速度目标，倾角由速度误差闭环生成，硬上限 1.5°。松开后速度指令按加速度回零，
倾角按 3.5°/s 释放，再交回驻车环。需要时使用前后反向选项匹配实际轮向。

档位不是角度：0 档位=不请求运动；1.0 档约等于 5 counts/50ms（100 counts/s）的稳态速度目标。机身倾角由闭环决定，
面板只读显示车端实际倾角（`target100 − O`），不会再把 `O±2°` 直接写成目标角。

移动期间驻车位置环以 400Hz 跟随当前位置（误差与位置速度请求保持 0），位置速度斜坡清空；松开后以当前位置为驻车点，
累计编码器坐标始终连续。遥控不会改写 O，运动中不要同时改平衡角。

左右转仍按住操作，默认 150Hz 差速，可调 5～300Hz，保留方向反转。停止按钮撤销两轴请求。

## 平滑、释放与反向

速度目标在 100Hz 更新，加速度上限 20 counts/50ms 每秒（0→满档约 0.5 秒）。倾角投入速率 2.5°/s、释放 3.5°/s，
任何一步都不会让目标角阶跃：进入运动时用当前速度环倾角做初值（`MotionLeanControl::seed`），
释放时先回零再叠加回速度环角。

倾角公式：`lean = 0.06×v_ref + 0.05×(v_ref − v_meas)`，限幅 ±1.20°。`v_meas` 不是 50 ms 瞬时速度，而是
**200 ms 位置差分净速度**（`NetSpeedEstimator`，10 ms 采样 20 点，并对位置做 3 点中值抑制单拍跳变）：
实测 0.5 s 内轮子来回摆 ±29 counts、66% 相邻样本换向，这是位置环的摆动而不是传感器白噪声，
卡尔曼滤不掉、只会加相位滞后；拉长窗口取净速度才是对症的做法。

前馈只补静摩擦（满档 0.6°），主调节交给速度误差：静止满档 1.10°，半速 0.85°，到达目标速度只剩 0.60°。
2026-11-06 两轮实车教训：前馈 0.12 时目标角被固定在 O+1.2°、与速度无关（同样参数下时走时停）；
改成 0.15 误差增益后外环超调，速度冲到 50+ counts/50ms、驻车环满权限急刹而摔倒。
两次对比见[逐次对比](validation/analysis/20261106-press-variance/report.md)与[失稳分析](validation/analysis/20261106-instability/report.md)。
反向命令自然经过零点，不需要额外的换向轨迹。

## 控制与保护

- 进入时 IMU 正常、姿态偏离 O ≤5°；姿态偏离 ≥10° 时外环权限为 0，只留直立 PD 救车。
- 运动期间速度环/驻车环的**角度修正**清零，但运动倾角本身来自速度反馈闭环，平衡环没有被移除。
- 面板每 100ms 维持当前请求；固件超过 350ms 没有刷新就回零；失焦、关闭、断线或 1.5 秒无遥测会撤销面板请求。
- 原 P/D/O/K/I/N 默认配置、speedLoopDirection=-1、电机极性、细分及 L/S/B/H 保持原值。

## 协议与遥测

能力标识：`TURN=2 MOVE=5 SMOOTH=1 MOTION=2 TILTMAX=2.00`。面板只认 `MOTION=2`；只有 `MOVE=5 SMOOTH=1` 的旧固件
是开环死倾角，接口数值含义不同，面板保持禁用并提示。

`^ 差速Hz,档位` 同时更新两轴，例 `^ 0,2`、`^ 0,1`、`^ 0,0`（整帧校验通过才改动请求）。旧 `@` 帧仅接受两轴均为 0，
旧 `~` 位置帧拒绝非零目标；旧配置解析与诊断字段继续兼容，不参与新前后运动。

遥测仍为 74 个数值项，字段定义不变（CSV 兼容 49/56/57/63/65/71/74 项）：

| 字段 | 含义 |
| --- | --- |
| manualControlMode=5 | 前后速度闭环模式 |
| manualReq1000 | 面板档位×1000（原始请求，单位不是度） |
| manualApplied1000 | 车端平滑后的档位×1000 |
| target100 | 最终目标角×100，减去 O 即实际运动倾角 |
| speed1000 | 实测速度，counts/50ms |

## 验证

black_f407zg 编译通过：RAM 8204 B、Flash 84652 B。主机回归 9 项通过，其中
`run_motion_drive_regressions.py` 覆盖速度斜坡、倾角上限、方向、释放无阶跃、带静摩擦的闭环收敛，
以及 200 ms 净速度的定速/单拍跳变/反向/复位；
`run_forward_regressions.py` 覆盖入口首拍 ≤0.025°、前进倾角 ≤1.5°、后退为负、释放后回到 `O + 速度环角`。
面板回归覆盖 `MOTION=2` 门控（旧固件保持禁用）、档位下发、按住/松开、反向、失焦撤销与 CSV 兼容。

首轮实车（2026-11-06 09:01 记录）满档只有 0.64° 平均倾角、净位移 20~30 counts/s，判为倾角不足 + 速度噪声打散，
据此把满档速度 5→10 counts/50ms、前馈 0.10→0.12、误差增益 0.05→0.02、上限 1.0→1.5°，并给速度反馈加 30 ms 低通，
详见[档位试验分析](validation/analysis/20261106-gear-trial/report.md)。

主机测试不模拟车辆动力学。实际方向、位移、静摩擦阈值、松开后的机械制动与稳定性仍需烧录后验证；
`limit=1.00°` 与 `feedForwardGain=0.10` 是经验值，实车不动时先加前馈再考虑抬上限。
