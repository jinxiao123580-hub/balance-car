# 编码器：MS42CG 配套磁编（AB 1024 线 + Z + PWM）

## 型号与来源

- 随 **MS42CG** 电机配套的磁编码器（电机尾部一体化），XH2.54-6PIN 单独引出。
- 厂商产品信息图：`docs/references/vendor/WHEELTEC-MS42DC/MS42C_产品信息_20261103.png`、`MS42C_引脚接线_20261103.png`。

## 关键参数

| 项目 | 值 |
| --- | --- |
| 输出 | AB 相增量（1024 脉冲/圈）+ Z 相零位（1 脉冲/圈）+ PWM 绝对位置 |
| 绝对位置精度 | 0.087°（PWM 通道） |
| 供电 | 3.3–5 V |
| 接口 | XH2.54-6PIN |
| 计数关系（厂商说明） | 磁环每转一圈，AB 输出 1024 个脉冲；每转一圈 Z 输出 1 个脉冲 |

## 编码器线序（6PIN）

| 针 | 定义 | 本项目是否使用 |
| --- | --- | --- |
| 7 | GND | 是 |
| 8 | Z 相 | **未接** |
| 9 | PWM 绝对位置输出 | **未接** |
| 10 | B 相 | 是 |
| 11 | A 相 | 是 |
| 12 | VCC（3.3–5 V） | 是 |

> 针号 7–12 是厂商图上的连续编号（电机 1–6 + 编码器 7–12），实际是两个独立的 6PIN 插座。

## 接线与固件

| 编码器 | STM32 | 说明 |
| --- | --- | --- |
| 编码器 1 A/B | PA0 / PA1 | 前轮 |
| 编码器 2 A/B | PB6 / PB7 | 后轮 |

- 固件只在 **A 相** 上挂 `attachInterrupt(..., CHANGE)`，ISR 里读 B 相判方向、计 ±1 → **2 倍频**，即 1024 × 2 = **2048 count/圈**。
- 没有用 4 倍频，也没有用 Z 相索引；`encoder2Direction = -1`（2026-08-21 实测两路计数符号相反）。
- 固件里没有显式 CPR 常数，速度/位置标定靠实测（工作区侧 `cpr_estimate.py`）。

## 已知问题

- enc2 间歇失效未查到根因（怀疑接插件/杜邦线），未测波形。
- Z 相和 PWM 都没引出使用：目前无法做"上电找零"或绝对角度校正，只能靠增量计数。
- 2 倍频分辨率是 2048 count/圈，低速时速度估计量化较粗；若以后换 4 倍频，所有速度/位置参数要重标。
