# 部件说明（每个部件一个文件）

这里放"具体每个部件"的细节：型号、参数、接线、实测数据、已知问题。
原始照片/手册/截图先丢进仓库根目录的 `_inbox/`，整理后结论写进对应文件，图片放 `docs/images/` 或 `history/media/`。

## 建议字段

每个 `<部件>.md` 用同一套小标题，缺的写"未知"，不要留空：

```
## 型号与来源
## 关键参数（标来源：铭牌 / 手册 / 实测 / 卖家页）
## 接线与引脚
## 实测记录（电压、电流、温度、波形）
## 已知问题
## 待验证
```
