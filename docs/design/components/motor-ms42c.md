## 接线与引脚（电机侧 6PIN，XH2.54）

| 针 | 定义 |
| --- | --- |
| 1 | A+ |
| 2 | 公共线 |
| 3 | A- |
| 4 | B+ |
| 5 | 公共线 |
| 6 | B- |

- 这是**带中心抽头的 6 线接法**：用四线驱动器（A4988 / DRV8825 / TMC2209）时，通常只接 1/3/4/6，把 2、5 两根公共线悬空（按全绕组用）。
- **本车实际怎么处理 2、5 两根公共线，未记录**——拆机时确认一次，写回这里。
- 驱动器相序：DRV8825 与 TMC2209 输出相序相反，换驱动器要核对转向（2026-09-28 实测）。

## 实测记录

- 2026-09-23：VREF 0.9 V。
- 2026-09-28：DRV→TMC 相序相反，`motor2Invert` 翻转后两轮一致。
- 2026-10：MKS TMC2209 独立模式运行。

## 已知问题

- 1.68 A 额定、1.65 Ω 内阻，12 V 下电流上升快；驱动器必须限流，否则低速易过流/发热。
- 静力矩 3.6 kg·cm 是保持力矩，高速段会明显下降（手册没给矩频曲线）。
