# 电源与配电

## 型号与来源

- 电池：**12 V 2200 mAh 锂电池**（用户 2026-11-03 口述；串数/电芯型号未记录，按 12.6 V 满电推断为 3S）。
- 电源模块：**自绘 PCB 上的板载电源**，贴片件为机器贴装（PCBA），不是外购成品模块。
- PCB 源文件：项目机械/PCB 目录下的嘉立创 EDA 工程（`*_Board1_1_*.epro2`、`*_PCB1_1_*.epro2`、`*_Schematic1_1_*.epro2`，2026-09-23）。

## 配电结构（据现有信息）

```
12V 锂电 ──┬── 驱动器 VM（A4988 / DRV8825 / TMC2209）
           └── 板载降压 ── 5V ──┬── 核心板 5V（经板上 3V3 稳压）
                                └── 外设
                           └── 3V3 ── IMU / 编码器 / 蓝牙 / TMC 逻辑
```

## 已知问题

- **上电 LC 尖峰烧过 A4988**（2026-08 汇报第 184 页）：当时的处置是外部并联大电容吸收尖峰。当前 PCB 是否保留这颗电容、容值与耐压多少，**没有记录**——换驱动器/加大电池后要复查。
- 3V3 余量只有 500 mA（若走核心板稳压），IMU、编码器、蓝牙、TMC 逻辑都挂在这路；加模块前先算电流。
- 12 V 直接进驱动器，没有软启动；频繁插拔电源仍有浪涌风险。
