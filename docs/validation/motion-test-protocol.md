# 前后运动验收测试规程（速度跟踪 · 姿态 · 停车）

适用固件：2026-11-06 之后的速度闭环版本（`PAR` 含 `MOTION=2`）。分析脚本：
`software/analysis/analyze_motion_test.py`。

## 1. 指标定义

| 指标 | 定义 | 数据来源 |
| --- | --- | --- |
| `v_ref` | 档位/2 × `MotionSpeedProfile::maxSpeed`（默认 8，即满档 8 counts/50ms ≈ 160 counts/s） | `manualReq1000` |
| `v_meas` | 0.5 s 位置差分 → counts/50ms（`Δpos/10`） | `pos100` |
| 稳态误差 | 按住段**后 50%** 的 `v_ref − v_meas` 均值，同时给百分比 | 同上 |
| 稳态波动 | 同一窗口 `v_meas` 的标准差 | 同上 |
| 延迟 | 按下 → `v_meas` 首次达到 10% `v_ref` | 同上 |
| 上升时间 | 按下 → 首次达到 90% `v_ref`（未达到记 None） | 同上 |
| 姿态偏差 | `pitch − O`：均值 / RMS / 峰值（按住全程） | `pitch100`、`O_balanceAngleOffset` |
| 姿态速度 | `|gyro100|` 峰值，单位 °/s | `gyro100` |
| 停车时间 | 松手 → `|v_meas| < 10% v_ref` | 同上 |
| 停车距离 | 同一区间的 `|Δpos|` | `pos100` |
| 停车过冲 | 松手后 3 s 内 `|v|` 峰值 − 稳态速度；姿态同理取 `|pitch−O|` 峰值 | — |
| 输出打满 | 按住段内 `|finalHz| ≥ 1750` 的采样数 | `finalHz` |

## 2. 测试序列（每项重复 3 次，同一地面、同一 O、同一电量段）

| 编号 | 操作 | 目的 |
| --- | --- | --- |
| T1 前进 | 档位 2.0，按住 2 s，松开，停 3 s | 前进稳态跟踪 |
| T2 后退 | 档位 2.0，按住 2 s，松开，停 3 s | 后退稳态 + 方向对称性 |
| T3 加速 | 档位 1.0 按住 1 s → 不松手切到 2.0 → 再按 2 s | 阶跃加速的过冲与恢复 |
| T4 减速 | 档位 2.0 按住 2 s → 切 1.0 → 再按 2 s | 阶跃减速 |
| T5 停车 | 档位 2.0 按住 2 s（到稳态）→ 松手 | 制动时间/距离/过冲 |
| T6 换向 | 前进 1.5 s → 立刻后退 1.5 s → 停 | 过零换向是否顿挫 |

操作要点：

- 每次按键之间**等车完全停稳**（面板“前后请求会撤销”提示消失）再做下一次；
- 同一天内不要在测试中途改 `O`、`X`、`K`；
- 面板保持“录制中”，测试结束后停止录制，得到的 CSV 就是分析输入。

## 3. 分析命令

```powershell
cd "D:\AI项目总库\02_机器人与机械工程\PlatformIO项目\pinghengche\balance-car-showcase"
python software\analysis\analyze_motion_test.py "docs\validation\recordings\<文件>.csv" --max-speed 8 --markdown
```

`--max-speed` 必须与固件当前 `MotionSpeedProfile::maxSpeed` 一致（默认 8）；`--md-out 结果.md` 可直接出表，
`--json 结果.json` 出机器可读版本，`--min-hold 1.0` 忽略过短的误触。

## 4. 初始通过标准（建议）

| 指标 | 目标 | 说明 |
| --- | ---: | --- |
| 稳态误差 | ≤ 25% | 当前实测 66~91%，是主要差距 |
| 稳态波动 | ≤ 2 counts/50ms | 目前 0.7~5.0 |
| 上升时间 | ≤ 1.5 s | 2 Hz 数据下分辨率 0.5 s |
| 姿态 RMS | ≤ 1.0° | 目前 0.72~0.97，已达标 |
| 姿态峰值 | ≤ 2.0° | 目前 0.96~1.36 |
| 陀螺峰值 | ≤ 60 °/s | 目前 ≤ 7，很干净 |
| 停车时间 | ≤ 2 s | 目前 0.5~3.5 s，不稳 |
| 速度过冲 | ≤ 3 counts/50ms | 目前部分段 >10 |
| 输出打满 | 0 | 目前 0 |

“当前实测”取自 `ble_tune_log_20261106_141856`（max-speed 10 的旧参数），换新参数后需重测。

## 5. 数据限制

- 遥测 2 Hz：上升时间只有 0.5 s 分辨率，过冲峰值可能被漏采；
- `v_meas` 是 0.5 s 差分，天然平滑，真实的 100 Hz 速度环行为看不到；
- 需要更细的动力学（例如判断阶跃响应的振荡频率）时，先启用固件里已设计的 20 Hz 调试帧
  （见 `.dsh/memory/decisions.md` 2026-11-04 条），再按同一脚本分析。
