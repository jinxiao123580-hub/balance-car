## 因果链

1. 新的 `0.15×速度误差` 对 **200 ms 净速度 + 2.5°/s 倾角斜率**的外环来说环路增益过高；
2. 一起步就顶到 1.5° 上限，速度迅速冲过目标（10 counts/50ms），但速度估计滞后 200 ms，倾角来不及收；
3. 实测速度冲到 **50~56 counts/50ms（1000+ counts/s）**，是目标速度的 5 倍；
4. 松手后驻车/速度环用满权限（±2°）急刹，机身被甩出 ±7°，直立环进入大角度、输出打满；
5. 大角度下外环权限归零、只剩直立 PD，车身一旦越过可恢复范围就倒。

负向那一次更糟：目标角 0.5 s 内从 5.69 跳到 4.59（−1.1°），轮子直接 −1750，速度 −50.7，随即甩尾。

所以问题不在“档位”，而是**外环把速度打过头**：上限 1.5° 对这个车来说已经是“重油门”，配合 200 ms 延迟必然超调。

## 建议的上车顺序（这次务必从低档开始）

1. 先烧本版，**档位 1.0**（目标 5 counts/50ms）测 3 次短按，确认 `pitch−O` 不再超过 ±2°、
   `finalHz` 不打满、速度不超过 15 counts/50ms；
2. 稳定后再上档位 2.0，仍只看“能不能走”，不追求速度；
3. 若 1.0 档就能稳定走但太慢，把 `feedForwardGain` 0.06→0.08 逐档加，**不要动 `speedErrorGain`**；
4. 若出现“起步就冲过头”，先把 `limit` 1.20→1.00，再考虑降 `speedErrorGain`。

任何一版只要出现 `finalHz` 长时间打满 + 速度超过 25 counts/50ms，就说明倾角上限对该车仍偏大。
