## 2. 占空比 PWM：能调加速度，不能调速度

工具 `software/analysis/ble_pwm.py`：300ms 周期内交替给 `O+Δ` 与 `O`，Δ=+1.5°。
固件完全跟得上：48 次写入 0 次失败。

`[有效]` `pwm_back02`（每档 2.5s）：

| duty | 速度 |
|---|---|
| 0% | −0.23mm/s |
| 10% | +1.30mm/s |
| 20% | +26.25mm/s |
| 30% | +11.57mm/s |
| 50% | 翻车（pitch 11.1°） |

`[已否证]` **占空比开环调速不成立**：20% 给 26mm/s、30% 反而只有 11.6mm/s，**非单调**。

`[有效]` 原因是机制性的：**Δ=0 只是"不加速"，不是"刹车"**。速度是加速度的积分，一旦破粘，车就以 Δ=0 匀速滑行下去；窗口内的位移取决于**什么时候破粘**，与占空比没有确定关系。duty 只决定平均斜率，决定不了速度值。

## 3. 因此调速必须闭环（下一步）

唯一能改变速度的办法是给**反向 Δ**（刹车）。所以正确的结构是：

```
v = 由编码器算出的实测速度
e = v_target − v
e > deadband  →  Δ = −Δon（前倾，加速前进）
e < −deadband →  Δ = +Δon（后倾，刹车/后退）
|e| ≤ deadband → Δ = 0
```

即 **bang-bang 速度环，Δ 只当油门/刹车开关用**；距离环套在速度环外面。因为门槛效应，Δon 必须取到能稳定破粘的值（后退 ≈+1.3~1.7°，前进 ≈−1.2°）。

`[待做]` 用实测 `speed` 字段（G 帧第 3 列，c/50ms，×20/1080 = mm/s）做这个速度环，5Hz 更新即可。
