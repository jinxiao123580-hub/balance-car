2. 后退 34mm

## 必须同时写进周报的限制

**单次演示成功不代表可重复。** 同一台车、同一组参数，六次尝试只有一次复现；
位移在 2~182mm 之间跳，指令方向与实际运动方向还会随机反向。
机制是静摩擦破粘时刻随机（0.5~6s），没有稳定工作点。
