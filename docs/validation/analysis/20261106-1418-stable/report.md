## 为什么慢：P 控制的稳态差

`lean = 0.06×10 + 0.05×(10 − v)`。实测稳态 v≈2~3 counts/50ms 时 lean≈0.95~1.0，
正好是"静摩擦+滚阻所需的倾角 ≈ 当前命令倾角"的平衡点。要更快就得在这个平衡点上再加倾角：

## 建议（一次只动一个）

1. **先动前馈**：`feedForwardGain` 0.06 → 0.08。它给所有速度同时加 0.2°，等效把平衡点往外推，风险比提误差增益低（0.15 那次就是增益过高导致超调摔倒）。
2. 若 0.08 下稳态仍不到 80 counts/s，再把满档 `maxSpeed` 10 → 13（提高误差项在低速段的推力）。
3. `speedErrorGain` 保持 0.05 不动；`limit` 保持 1.20°。
4. 每轮只看三件事：`pitch−O` 不超 ±2°、`finalHz` 不打满、速度不超 25 counts/50ms。任一越界就退回上一档。
