# 点动参数输入与车端生效状态修正

日期：2026-10-30，Asia/Shanghai。本轮修面板，未修改或烧录固件。

## 复现证据

[14:23:58记录](../../recordings/ble_tune_log_20261030_142358_463_p28076.csv)共229行完整遥测，全部车端位置P=0.0050、倾角上限0.30°，实际位置倾角受0.30°限制。用户在面板输入过P=0.0200、上限0.50°，但车端回显仍是旧值。记录指纹见evidence.json，原始CSV保留。

现场面板日志出现“请停止点动并等待回正后，再应用点动参数”和“点动参数需连接位置倾角固件”。旧界面只在日志提示拒绝原因，保留新输入，未突出未生效状态；已连接/旧回显也可能保留在界面上。用户随后确认控制板已断电，本轮无法实测新上限接受情况。

这证明新值没有生效，不证明硬件或当前固件源码的最大上限只有0.30°。当前固件解析允许0.05～0.50°，配置分发回归已验证0.50可被解析；设备实际运行的镜像仍需上电后确认。

## 面板修正

- 新增明确的未连接、待读取、参数未应用、等待确认、已生效和应用失败状态。
- 输入与车端值不一致或配置等待确认时，前后按钮禁用；停止与转向保持原有控制。
- 配置应用仅在连接、遥测新鲜、点动已结束且位置倾角已回零时允许。
- BLE写入成功仍需匹配的JOGCFG回复或匹配的实际遥测确认，才显示生效。
- 断线、发送失败、确认超时和旧固件把配置当成诊断的情况会显示原因，保留真实车端值。
- 过时/超时配置在BLE串行队列内再次核对代号，取消后不能晚到下发。
- 重连后清除旧确认，重新读取；上电恢复默认参数的行为不变。
