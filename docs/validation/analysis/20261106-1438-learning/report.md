工作区其实是一条窄带：**0.5~0.7° 最快，越贴近 1.2° 上限越慢**。原因是贴边时车身已接近可恢复极限，
轮子只能左右追着摇，净位移反而消失——1.2° 的 70 个样本是全部样本里最多的，说明控制器大部分时间都顶在墙上。

## 所以“学习没用”的真实原因

1. 学习把倾角额外推高 0.30°，而基础量本身已经在 1.0~1.1°，叠加后直接撞上限 → **增量被限幅吃掉，等于没加**；
2. 撞上限之后进入“摇不动”的极限环，速度不升反降——学习在错误的方向上加力；
3. 学习量在 1~2 s 内就冲到 ±0.30（增益 0.02 × 误差 8 ≈ 0.16°/s），没有机会做细调；
4. 它只在 |v|>0.8 时才学，所以“卡住”的状态学不到任何东西——而那正是最需要补偿的状态。

## 本次调整（把工作点挪回窄带内）

| 参数 | 旧 | 新 | 依据 |
| --- | ---: | ---: | --- |
| `limit`（倾角上限） | 1.20° | **0.90°** | 1.2° 处中位速率 41，0.9° 处 154 |
| `maxSpeed`（满档） | 10 | **8** counts/50ms | 静止时基础倾角 0.48+0.40=0.88，正好在 0.90 以内，不再一按就顶边 |
| `learnLimit` | 0.30° | **0.15°** | 留出上限余量，学习不再被限幅吃掉 |
| `learnGain` | 0.02 | **0.01** | 2~4 s 才到上限，允许细调 |

面板同步：档位换算 ×5 → **×4 counts/50ms**，状态栏上限提示改为 0.9°。

预期：静止满档基础倾角 0.88°、学习再加 ≤0.15°（被 0.90 截断）→ 工作在 0.8~0.9° 带内而不是贴边；
速度目标 8 counts/50ms（160 counts/s）与实测“0.6~0.7° 能跑 200 counts/s”同一量级。

## 上车验证

1. 烧录后先做 3 次前进、3 次后退，每次 1~2 s；
2. 看 `manualI1000`：应在 0~150 之间缓慢变化，**不应一按就跳到 150**；
3. 看 `pitch−O`：应停在 0.7~0.9°，不再长期贴 0.90 上限；
4. 判据不变：`finalHz` 不打满、速度不超 25 counts/50ms、无倒地。

如果这版仍在 0.9° 附近“摇不动”，那就不是倾角量的问题，而是该地面/该车的静摩擦已经接近 1°，需要换地面或检查轮子打滑。
