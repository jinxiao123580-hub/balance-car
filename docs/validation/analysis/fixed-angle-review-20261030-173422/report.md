## 结论

当前正向+2°动作过强，三次均在松开后的采样中出现大角度偏离与1750Hz输出饱和。负向−2°没有相同表现，不能简单概括为双向2°都必然失稳，也不能仅凭此记录排除平衡角偏置、动力学方向差异或人工扶车影响。建议下一轮正负先按相对O ±0.5°测试，再按0.1～0.2°递增。这个建议是调试起点，尚未实车验证，不保证必能移动或稳定。

## 负向与方向差异

共6段−2°活动请求，最长活动采样跨度6秒，所有段及其后约3秒窗口最大|pitch−O|≤2.33°，最大STEP输出637Hz。多段实际俯仰接近0°，与O−2°一致。它们明显比正向温和，因此还应复核O=2°是否为当前装配与载荷下的真实平衡点，以及两方向的机械/驱动响应。此差异不能直接证明某个方向电流不足或电机故障。

## 交接版本尚不一致

共20个姿态偏差小于5°、且正常速度环恢复权重介于0和1的完整采样，positionHoldSuspended全为0，位置误差也不为0。例如57.267秒权重0.362、位置误差−45.5计数；98.767秒权重0.058、位置误差−12.5计数。

另外，后两次正向操作在位置环仍暂停、位置误差为0时已经达到1750Hz上限（73.767秒、113.267秒），不能将起始失稳全归为位置环打架。

这与最新源码“恢复权重未满时驻车目标仍跟随当前位置、暂停位置环、误差为0”的行为不一致。可以确认这份日志未体现该项最新修复，不能仅靠mode=5判定已刷入最新构建，因为修复前后模式号相同。下一轮应先确认该修复进入实车，再评价剩余制动问题。当前证据不能判断具体烧录了哪一个二进制。

## 为什么仅减小角度还不够

固定倾角运动期间旁路速度反馈。松开只把目标角平滑拉回O，不是主动给出随轮速变化的制动目标；速度环又要等倾角回零后才渐入。正向已有明显速度时，这种延迟可能来不及制动。三次正向失稳都发生在松开之后，因此需要同时关注角度幅值、松开时的速度、回零耗时及速度反馈交接，不能仅继续放慢回零轨迹。

建议先验证最新驻车同步修复，再减小到±0.5°短按对比。如果还出现松开后加速或大偏角，再调整松开时速度反馈的介入时机。2Hz记录能说明趋势，不能证明400Hz每一拍无突变，控制层面的制动效果仍需实车验证。
