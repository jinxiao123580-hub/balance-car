## 4. 标度（派生量，非独立标定）

`finalBalanceOutput` 单位是**步进频率 Hz**，限幅 `BALANCE_OUTPUT_LIMIT_HZ=1750`（main.cpp:497）；平衡输出是积分器（main.cpp:4191）。
由悬空 2s→220mm 且必然饱和反推：**1 step = 0.0625mm，1Hz = 0.0625mm/s，1750Hz = 109mm/s = 极速**；轮周长≈200mm（r≈32mm）、3200 步/转；`vehiclePosition/10.8 = mm` 与之自洽。

## 4.7 对“机械结构不平衡”的最终回答

- 机械偏置**存在**：TF=0 时前进 −8.7、后退 −10.6，两向都往后走，约 −5mm/s，速度指令压不住；要有 +0.5° 的前向偏置才能让前进转正。这个偏置值得用 TF/TB 配掉（方案 A）。
- 但机械偏置**不是“推不动”的原因**：现在车不动，是因为控制器给出的倾角只有 0.02°，比门槛小 25~50 倍。**修机械不会改变这一点**；反过来，只要给出 0.5° 的倾角，车立刻动（TF 已证）。

## 4.9 用户实测：O=4.5 → 后退（推翻 §4.7 的“两向都往前”）

`[有效]` 用户手测 **O=4.5（基准 2.30 +2.2°）车能后退**。⇒ **增大 O = 后退**；O 是唯一够量级的倾角杠杆。

由此三处要改口径：
1. `FINDINGS2` 把 **O=4.0 记成“已否证／持续单侧倾倒”是误判**——那是后退动作跑到 109mm/s 速度上限后撑不住，不是 O 无效。O 是有效的运动指令，只是必须限时。
2. **TF/TB 被 clamp 在 ±1.0°，而且挂在只产出 0.02° 的运动环路上**，所以加大 TB 只是让环路更用力“往前走”，方向不变——与用户观察一致。**O 是直接偏 2.2°，才够门槛。**
3. 结论修正：**这台车可用的运动原语是“改 O 给固定倾角偏移，限时后归位”**，速度指令（`^`）与 TF/TB 都不够用。

`[待验证]` `pos` 符号与物理方向是否一致（用户看到 TB 加大仍往前走，而编码器给 −93mm）。若两者矛盾，说明轮子在桌面上打滑，**所有基于编码器的位移数据都要重估，只能靠相机或肉眼**。

## 11. 成对行程（后退→前进回原点）：发现是双稳态（20:55~21:02）

`[有效]` **Δ=+1.3° 是双稳态**，同样条件三次：**3.11 / 48.57 / 3.77 mm/s**（sd 21.3）。要么慢爬 3~4mm/s，要么直接冲到 48mm/s。

`[有效]` 差别在**保持时长**：2.5s 的三次基本都慢爬（7.96 / 126.67 / 9.44mm）；8s 的两次都起飞（121 / 92mm）。⇒ **先粘几秒，再突然破粘跑掉**，破粘时刻在 0.5~6s 之间随机。这就是“静摩擦 + 积分器”的典型行为，也解释了历史上“有时踢得动有时踢不动”。

`[有效]` 后果：Δ 定值 + 限时**不能**得到可重复的位移；位移的重复性由“破粘时刻”决定，不受控。

`[待验证]` 解法方向：**短脉冲微步驱动**——Δ=1.3 只给 300~400ms 就释放，停顿后再判位，逐步逼近目标。每次脉冲即使破粘也只跑 ~10mm，把误差约束在 4Hz 可观范围内。

`[问题]` 回程仍超调（rep1 用 3 个脉冲退回 −153mm），净位移 −2.6 / −26.3 / −39.2mm，车整体在往前漂，需要把 tol 收紧或降低前进 Δ。

## 12. 后退重复性实测（21:00~21:08）：结论是「不可重复」

工具 `ble_microstep.py`：保持 Δ 逐帧判位，**到位即收令**（破粘后最多再走一个 250ms 遥测周期）。证据 `back_quant01.*`、`back_quant02.*`、`dfind_back02.*`

Δ=+1.3° 后退的全部结果（同一台车、同一晚）：

| 保持方式 | 后退位移 |
|---|---|
| 8s 固定 | +121.1 / +92.0mm |
| 2.5s 固定 | +7.96 / +126.67 / +9.44mm |
| 到位截断（1.2~3.2s） | +67.1 / +43.9mm |
| 12s 固定 | **+19.9 / +4.1 / −21.9mm** |

`[已否证]` **“Δ 偏置 + 限时”不能得到可重复的后退位移**：12 秒给出的位移可以比 1.2 秒还小，甚至反向（−21.9mm）。sd 在 60~90mm 量级，比 50mm 目标还大。对 Δ 和时间**都不单调**。

`[有效]` 机制：**静摩擦门槛 + 破粘时刻随机**。破粘后立刻就是 50~60mm/s（+67mm/1.19s、+121mm/8s），不破粘就只是 0.3~2mm/s 的蠕爬。中间没有稳定工作点。

`[有效]` 因此今晚所有“Δ 扫描”的 sd 都很大，根源不是测量噪声，而是这个双稳态本身。

`[有效]` **换向是另一个危险点**：后退到 50~60mm/s 后立刻用 Δ=−1.1~−1.2 反向，会连续把车掀翻（pitch −4.5° / −16.2°）。回程前必须等 3 秒以上，且前进 Δ 要更小。

## 13. 结论与建议的下一步

`[结论]` 这台车目前**没有可用的速度/位置指令通道**：
- `^` 速度指令 → 倾角：实测 ~0.02°，够不到门槛；
- `TF/TB`：被 clamp ±1.0°，且挂在同一条环路上，只有 TB→前进有效（命名反了）；
- `O` 偏置：能给出任意倾角，但位移由“破粘时刻”决定，不可重复。

`[建议]` 先做机械项（零成本，30 秒）：断电手推前后各 5cm，若后推明显更涩/有卡点，就是单向干涉，按方案 D 排查轮子—挡泥板—车架—排线。**在这之前不要再加 Δ 硬试**，因为双稳态会让每次结论都打架。

## 14. 口径更正（2026-11-13，用户指定）——§8 结论撤回

`[已否证]` 本文 §8 当时写的“机械结构偏置成立、就是后滚阻力”，是**仅凭编码器口径**的推断。

后续相机实测（`20261113-nocam/demo04`）：同一次测试里编码器摆动 77.4mm，相机跨度只有 9.6mm，两者差约 8 倍；用户现场观察为“轮子前后晃动、车体几乎不动”。

⇒ 编码器读数**不能当作车体位移**，因此 §8 的后滚阻力结论**不成立**。

`[当前口径]` 前后不对称按三条机制并列、均待验证，**不归因于结构不平衡**：
1. 静摩擦破粘阈值存在方向差异（后滚需要更大 Δ）；
2. 编码器测的是轮子转角，轮子往复摆动时其直流分量不代表车体位移；
3. 相机与编码器两个量具读数不一致，至少有一个测的不是同一件事。

`[区分方法]` 以相机为真值、同一 Δ 做双向对照、长窗口（≥60 s）统计。
