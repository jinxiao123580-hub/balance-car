# 重心偏置的两轮自平衡车：建模与前后运动方案

日期：2026-11-12
适用：pinghengche / balance-car-showcase（STM32F407 + 步进轮 + BMI270）
前提：IMU 不在车体中心，COM 前后偏置。

---

## 0. 结论先行

1. **前后重心偏置本身不会造成运动不对称**，它被平衡点 `O` 完全吸收了——这就是为什么 O=2.0° 而不是 0。
2. 真正造成"前进不走、后退能走"的是三个量叠加：**静摩擦阈值 F_s、车体固连的常值力偏置 F_b、控制环倾角权限不足**。
3. 解法不是拆机械，而是**在倾角指令上加方向性前馈（TF/TB）+ 起步脉冲**，并且**把速度环的倾角权限从 0.16° 提到门槛之上**。

---

## 1. 模型

### 1.1 符号

| 符号 | 含义 |
|---|---|
| θ | 车体俯仰角（绕轮轴） |
| s | 轮子位移（前进为正） |
| M, J_b | 车体质量、绕自身 COM 的转动惯量 |
| l | 轮轴到车体 COM 的距离 |
| d | COM 相对轮轴的**前后偏置**（前为正） |
| R, J_w | 轮半径、轮转动惯量 |
| τ | 电机输出力矩（两轮合计） |
| F_s | 轮地静摩擦阈值（等效为力） |
| F_b | 车体固连的常值力偏置（拖拽/低垂件/线缆） |

### 1.2 运动方程（小角度线性化）

绕轮轴的力矩平衡：

```
(J_b + M l²) θ̈ = M g (l·θ + d) − M l s̈ − τ + M l ẍ_bias      (1)
```

轮子平动：

```
(M + J_w/R²) s̈ = τ/R − F_s·sign(ṡ) − F_b                     (2)
```

其中 `M g d` 就是偏置项：它等效于把平衡角整体平移了

```
θ_eq = −d / l                                                (3)
```

### 1.3 关键推论：偏置被 O 吸收

控制器把 `targetBalanceAngle` 定在 O 上，闭环稳定时 θ → O。
代入 (1) 的稳态（θ̈ = s̈ = 0）：

```
M g (l·O + d) = τ_hold → 只要 O = −d/l，τ_hold = 0
```

也就是说：**只要 O 标定正确，静态上这个车和"重心居中"的车完全等价**。
O=2.0° 不是故障，它是 `d/l = −tan(2°) ≈ −0.035` 的直接读数——车体 COM 在轮轴后方约 3.5% 的摆长。

> 这也是"用悬空平衡角去反推重心"必然失败的原因：两边测的是同一个量 d/l，只是换了个坐标系。

## 2. 不对称从哪来

把 (1)(2) 在 θ = O 处展开，令 ψ = θ − O，所有静态项归零后：

```
(J_b + M l²) ψ̈ = M g l ψ − M l s̈ − τ + 外扰
(M + J_w/R²) s̈ = τ/R − F_s·sign(ṡ) − F_b
```

对同一个 |lean| 的正负两个方向，方程是**镜像对称的**，除非：

### 2.1 静摩擦阈值 F_s（主因）

要起步必须满足

```
|τ/R| > F_s + F_b·sign(目标方向)          (4)
```

若 `F_b > 0`（车体固连一个向后拽的常值力，例如低垂件刮地、排线拖拽），则

- 前进：`τ/R > F_s + F_b` —— 要求更大
- 后退：`τ/R < −F_s + F_b` —— 要求更小

**这就是"前进不走、后退能走"的完整机制。** 它跟"重心偏置"只是间接相关：偏置让车必须常驻一个非零倾角，任何刮地/线缆的接触都会在这个倾角下被放大成单向拖拽。

### 2.2 控制环倾角权限不足（次因，可量化）

今天实测：gear 1.0 时速度环生成的倾角只有 **+0.16°**，而起步门槛是 **0.5~1.0°**。
按 `a ≈ g·θ`：

| lean | 等效加速度 a | 4s 应走 |
|---|---|---|
| 0.16° | 0.027 m/s² | 220 mm |
| 0.5° | 0.085 m/s² | 680 mm |
| 实测 4s | ~0 mm | → **被 F_s 吃掉** |

也就是说 **F_s 的等效加速度 ≥ 0.085 m/s²**，而控制环长期工作在 0.027 m/s² 以下——它永远推不过门槛。

### 2.3 为什么加大 TB 会突变

实测（gear 0.5，3s）：

| TB | 后退位移 |
|---|---|
| 0.00 | −5.9 mm |
| 0.10 | −50.5 mm |
| 0.20 | −59.1 mm |

0.1° 换来 9 倍位移，说明系统工作在**阈值附近**：TB 不是线性增益，是把工作点从"摩擦死区"推到"滚动区"的开关。这决定了配平必须**小步长（≤0.05°）+ 每步实测**，不能按公式算。

## 3. 解决方案（按性价比排序）

### 方案 A：方向性倾角前馈（固件已有，只是没启用）

`motionLean.forwardTrim / backwardTrim` → 命令 `TF` / `TB`，范围 ±1.0°，进 flash。

```
τ_cmd = speedLoop(ψ, ψ̇) + trim(dir)·outerLoopAuthority
trim(forward) = forwardTrim
trim(backward) = −backwardTrim
```

**它恰好抵消 (4) 里的 F_b**：`F_b/(M g)` 就是需要的配平角。
当前 `TRIM=0.000/0.000`，等于明知有偏置却不补偿。

标定方法（按之前的 ±0.05 手工收敛，不用自动搜索）：

1. `TB 0` 基线，±0.5 档成对测 3s，记前进/后退位移
2. 前进偏小 → 加 `TF +0.05`；后退偏大 → 加 `TB −0.05`
3. 每步重测，判据：两向位移差 < 5mm 且符号一致
4. 收敛后 `SAVE`

### 方案 B：起步脉冲（已实现，FW=20261112C）

`KICK_DEG=0.5`、200ms、每条指令最多 2 次、`|pitch−O|<1°` 才踢。
它是**把工作点瞬间推过 F_s**，与方案 A 互补：A 解决稳态偏差，B 解决起动静摩擦。

### 方案 C：提高速度环倾角权限（需改固件）

现在 gear 1.0 → 0.16°，经过 `outerLoopAuthority` 和 `ManualPitchControl` 两道缩放。
把 `speedKp`（K）或 authority 曲线上调，让 gear 1.0 至少能到 **0.4~0.5°**。
风险：过大容易越过平衡能力，须配合 `KICK_MAX_TILT_DEG` 类似的限幅。

### 方案 D：机械上消除 F_b（根治）

在轮子不转时用一张纸沿车底前后抽拉，找出刮地点；重点查 50mm 标签支架、螺丝头、排线。
只要 F_b 归零，(4) 就恢复对称，A/B/C 都可以只留很小的补偿量。

---

## 4. 建议的执行顺序

1. **先做 D 的排查**（10 分钟，零成本）：纸片抽拉法找刮地点
2. **A 标定**（每轮 40 秒，3~4 轮收敛）
3. 若 A 之后 gear 1.0 仍不动，再做 **C**（改固件、加权限）
4. 最后测加减速与停车
