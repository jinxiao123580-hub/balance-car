## 一、已被证实（可直接引用）

### 1. 标度（本次实证，不再是推算）
`[有效]` 悬空测试 `air05.g.csv` 78 帧里 `hz` **全部正好 1750**（= `BALANCE_OUTPUT_LIMIT_HZ`），总位移 1992mm / 20s。
⇒ **1 step = 0.0625mm；1Hz = 0.0625mm/s；1750Hz = 109mm/s = 本车极速**；轮周长≈200mm（r≈32mm）、3200 步/转；`pos/100/10.8 = mm`。

### 2. 符号
`[有效]` **`pos` 为正 = 后退，为负 = 前进。**

### 3. 电机与编码器是好的
`[有效]` 同一帧内 `∫hz × 0.0625mm` 对比编码器位移：FWD `pred/disp = 0.88`、BWD `1.23`。
⇒ **有指令就跟着转**，无失步、无驱动故障、无编码器故障。

### 4. `^` 指令不是倾角指令
`[有效]` main.cpp:3556：`^ 0,x` 只给速度目标（`normalized*maxSpeed`），倾角由速度误差生成，
`motionLean.limit=0.90°`、`feedForwardGain=0.06`、`speedErrorGain=EG=0.05`。
实测 `^0,±1.0` 与 `^0,±2.0` 产出的倾角只有 **~0.02°**（target 停在 O），比起步门槛 0.5~1.0° 小 25~50 倍。

### 5. O 是唯一够量级的执行器
`[有效]` `O 4.50` → target 实测 4.68/4.70；`O 0.10` → −0.09/0.05。**O 通道正常、精确、可用。**
`[有效]` 但 Δ=±2.2° 超出可持续范围（109mm/s 上限 0.29s 就吃满），两向都会翻。

### 6. Δ 门槛表（Δ = 相对 O 的差值）
| Δ（后退为正） | 保持 | 结果 |
|---|---|---|
| +0.5° | 20s | +5.9mm（0.30mm/s），与 Δ=0 对照 0.21mm/s 无差别 |
| +0.7° | 20s | +13.4mm（0.67mm/s），噪声边缘 |
| +1.0° | 8s | +32.3 / +7.3mm（4.0 / 0.9mm/s） |
| **+1.3°** | 8s | **+121.1 / +92.0mm（15.1 / 11.5mm/s）** |
| +1.6° | 8s | >400mm（>50mm/s） |
| +2.2° | 1.2s | 翻车 |
| −1.2°（前进） | 1.2s | **−93.2mm（78mm/s）** |

### 7. 前后不对称
`[有效]` 同一 |Δ|=1.2°：前进 −93.2mm，后退 +3.5mm，**差 27 倍**。后滚阻力明显更大。

### 8. 换向会掀翻
`[有效]` 后退到 50~60mm/s 后立刻用 Δ=−1.1~−1.2 反向 → pitch −4.5°/−16.2° 翻车。回程前须等 ≥3s 且前进 Δ 更小。

### 9. 双稳态（今晚最重要的发现）
`[有效]` **Δ=+1.3° 的位移不可重复**，同一台车同一晚：

| 保持方式 | 位移 |
|---|---|
| 8s 固定 | +121.1 / +92.0mm |
| 2.5s 固定 | +7.96 / **+126.67** / +9.44mm |
| 到位截断（1.2~3.2s） | +67.1 / +43.9mm |
| 12s 固定 | **+19.9 / +4.1 / −21.9mm** |

12 秒的位移可以比 1.2 秒还小、甚至反向。**对 Δ 和时间都不单调**，sd 60~90mm（比 50mm 目标还大）。
机制：**静摩擦破粘时刻随机（0.5~6s）**。破粘后立刻 50~60mm/s，不破粘就 0.3~2mm/s 蠕爬，中间无稳定点。

### 10. TF/TB 命名是反的
`[有效]` TB（"后退配平"）加大 → **前进** 31mm/s（`tb_sweep02`：TB 0/0.3/0.6/0.9 → −19.5/−38.5/−28.7/−93.0mm）。
TF 加大 → 几乎不动（clamp ±1.0°，且挂在同一条死环路上）。

## 四、仪器教训（今晚废掉多轮的直接原因）

1. **BLE 写入必须 `response=True`**，`response=False` 会被静默丢弃；判断命令是否送达看 `req` 列。
2. **改 O 前必须 `^ 0,0`**（与 SAVE 同族的门控），否则命令被丢弃。
3. **4Hz 遥测 vs 脉冲宽度**：400ms 窗口只落 1 帧。位移一律用"发令前/收令前"的单点读数。
4. **pitch 帧里是百分度**，要 /100；判翻车用 `|pitch−O| > 6°`。
5. **中止也必须写盘**：`return 4` 会跳过写盘，今晚丢了两份数据。
6. **说"能走"前先区分"蠕爬"和"破粘"**：0.3mm/s 和 50mm/s 都叫"走了"，差 160 倍。
