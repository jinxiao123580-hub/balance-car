`[有效]` 两侧都在 **10.80.0.0/15**：Windows `10.81.39.207/15`（WLAN）↔ 下位机 `10.86.121.114/15`（有线），

（`本地连接* 9/10` 是 169.254.x 的未连接虚拟口）⇒ **「本机热点」这条路径当前不成立**。

### 5.1 DDS 可用性实测（决定方案）

| 测试 | 方法 | 结果 |
|---|---|---|
| UDP 单播 | slave 绑 7447，Windows 发 | **通**，slave 收到 `('10.81.39.207', 52378)` |
| UDP 组播 | slave 加入 239.255.0.1:7448，Windows 发 | **不通**（`MCAST_NONE timed out`） |

`[有效]` **组播被拦**（WiFi↔有线桥接常见）⇒ ROS 2 默认组播发现跨机**必然失败**，
必须配静态对端（§6.3）。单播 UDP 通，所以静态对端方案可行。

`[有效]` Windows 防火墙三个 profile 全开（Domain/Private/Public=True）。ROS 只在 slave 上跑时不受影响；
若要 Windows 侧也看到话题，另需放行入站 UDP 并配静态对端（不在本次范围）。

## 6. 部署方案（每条可直接执行，含预期输出）

### 6.0 需要**用户动手**的物理步骤（只有人能做的）

1. **断电**。把平衡车电池断开，确认 STM32 不供电。
2. **接 GND（必须最先接）**：USB-TTL 的 `GND` ↔ STM32 板 `GND`。
   两块板不共地时，信号会乱码甚至打坏 IO。
3. **TX/RX 交叉**（固件 `main.cpp:130` 已确认：`USART3 PB10=TX / PB11=RX`）：
   - USB-TTL `RXD` → STM32 **PB10**（板子的 TX）
   - USB-TTL `TXD` → STM32 **PB11**（板子的 RX）
4. **不要接 VCC/3.3V/5V**（板子自己供电，接 VCC 会倒灌）。电平必须是 **3.3V TTL**，不能用 5V 适配器的 5V 输出。
5. **必须先把 JDY-23 从 PB10/PB11 上摘掉**（或至少断开它的 TX）——
   否则 JDY-23 的 TX 和适配器的 TX 会同时驱动 PB11，形成总线冲突。
6. 上电顺序：**先接好 GND → 再接信号 → 最后给车上电**；拆线时反过来（先断电，再拆信号，最后拆 GND）。
7. 把 USB-TTL 插到下位机的 USB 口，然后执行 `dmesg | tail`，**预期**看到类似
   `ch341-uart converter now attached to ttyUSB0` 或 `cdc_acm ... ttyACM0`。

> 注意：9600 8N1，无流控。UART 线建议 ≤30cm，长线在 9600 下也容易受干扰。

### 6.1 确认设备与权限

```bash
dmesg | tail -5                      # 预期出现 ttyUSB0 或 ttyACM0
ls -l /dev/ttyUSB0                   # 预期 crw-rw---- 1 root dialout
groups | tr ' ' '\n' | grep dialout  # 预期 dialout（jx 已在组内，无需 sudo）
```

### 6.2 纯 Python 冒烟测试（不装包、不开 ROS）

```bash
cd <项目>/software/ros
python3 - <<'PY'
import backends, gframe
b = backends.UartBackend("/dev/ttyUSB0", 9600); b.open()
b.write_line("?")
import time; t=time.time()
while time.time()-t < 3:
    for line in b.read_lines(0.2):
        st = gframe.parse_gframe(line)
        if st: print("pos=%.1f pitch=%.2f hz=%.0f" % (st.pos_mm, st.pitch_deg, st.hz))
        elif line.startswith("PAR:"): print("PAR:", line[:60])
b.close()
PY
```

**预期**：先打印一行 `PAR: TURN=2 ... O=4.00 ...`，随后每 250ms 一行 `pos=... pitch=... hz=...`。
若无输出：① 检查 TX/RX 是否交叉；② 检查共地；③ 用示波器/逻辑分析仪看 PB10 有无数据。

### 6.3 跨机 DDS（**组播不通，必须显式配静态对端**）

在下位机建 `/tmp/fastdds_peers.xml`（**只写 /tmp**，不改系统）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<profiles xmlns="http://www.eprosima.com/XMLSchemas/fastRTPS_Profiles">
  <transport_descriptors>
    <transport_descriptor>
      <transport_id>udp_only</transport_id>
      <type>UDPv4</type>
    </transport_descriptor>
  </transport_descriptors>
  <participant profile_name="peer_participant" is_default_profile="true">
    <rtps>
      <userTransports><transport_id>udp_only</transport_id></userTransports>
      <useBuiltinTransports>false</useBuiltinTransports>
      <builtin>
        <initialPeersList>
          <locator><udpv4><address>10.81.39.207</address></udpv4></locator>
        </initialPeersList>
      </builtin>
    </rtps>
  </participant>
</profiles>
```

运行前：

```bash
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=42                 # 校园网是 /15，务必避开别人的默认 0
export FASTRTPS_DEFAULT_PROFILES_FILE=/tmp/fastdds_peers.xml
```

`[待确认]` Humble 的 `rmw_fastrtps` 是否支持 `ROS_STATIC_PEERS` 环境变量（该变量在较新版本才有）。
先用上面的 XML 方案，它是 fastrtps 2.6 文档化的路径；`ROS_STATIC_PEERS` 若可用可省掉 XML。

### 6.4 起节点（单进程双职责，因为一个串口不能被两个进程打开）

```bash
cd <项目>/software/ros
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=42
python3 car_state_node.py --device /dev/ttyUSB0 --cmd-topic /car/cmd
```

另一个终端：

```bash
source /opt/ros/humble/setup.bash; export ROS_DOMAIN_ID=42
ros2 topic list            # 预期 /car/state /car/cmd /rosout /parameter_events
ros2 topic hz /car/state   # 预期 average rate: 4.xxx
ros2 topic echo /car/state --once
# data: '{"stamp_ms":...,"pos_mm":-979.3,"speed_mm_s":-5.33,"pitch_deg":2.25,...,"hz":-142.0,...}'
```

### 6.5 下发指令（**先在车架空/断电情况下验证**）

```bash
ros2 topic pub --once /car/cmd std_msgs/msg/String "{data: '?'}"
ros2 topic pub --once /car/cmd std_msgs/msg/String "{data: '^ 0,0'}"      # 急停
ros2 topic pub --once /car/cmd std_msgs/msg/String '{data: "{\"cmd\":\"O\",\"value\":4.5}"}'
```

**安全**：`O` 与 `^` 会立刻让车动。首次联调请把车悬空（轮子离地），只验证解析与回显。

## 7. 产物

| 路径 | 内容 |
|---|---|
| `software/ros/gframe.py` | G 帧解析（含 `pos/100/10.8`、`speed/1000`、`pitch/100` 的换算）＋指令拼装＋白名单校验 |
| `software/ros/backends.py` | `UartBackend`（**标准库 termios**，可直接用）/ `PyserialBackend`（占位）/ `BleBackend`（占位） |

**校验结果**：

```

```

> 选 `std_msgs/String` 装 JSON 而非自定义 msg：下位机只有 `ros-humble-*` 二进制包，
> 这样 `python3 xxx.py` 直接跑，**无需 colcon build、无需装任何东西**。
