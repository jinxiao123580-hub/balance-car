## 根因：倾角是固定偏置，不是速度调节

旧公式 `lean = 0.12×v_ref + 0.02×(v_ref−v)`：满档时前馈就占 1.2°，速度误差项最多再加 0.2°。
也就是说**只要按着，目标角就固定在 O+1.2°，与当前速度无关**。

- 车身一旦被拉到这个角度（轮子只滚一点点就能实现），直立 PD 的误差≈0，输出≈0，车停在这个角度上或者原地摇；
- 轮子是否继续滚，取决于初始条件和静摩擦，而不是控制律——所以同一份记录里既有 +241 counts/s，也有 +13 counts/s；
- 速度反馈只在很窄的范围内起作用（±0.2°），无法把“停住”的状态拉回“滚动”。

## 改法

把主导权交给速度误差项，前馈只补静摩擦：

| 参数 | 旧 | 新 |
| --- | ---: | ---: |
| `feedForwardGain` | 0.12 | **0.03** |
| `speedErrorGain` | 0.02 | **0.15** |

效果（按新公式 `lean = 0.03×v_ref + 0.15×(v_ref−v)`）：

| 状态 | 倾角 |
| --- | ---: |
| 静止、满档 | 1.80° → 限幅 1.50° |
| 半速（v=5，v_ref=10） | 1.05° |
| 到达目标速度 | 0.30°（只剩摩擦补偿，不再持续加速） |

主机闭环回归（带静摩擦与阻力的简化对象）：v 收敛到 **9.32**（目标 10，P 控制的稳态差 7%），
而旧参数在同对象上冲到 21.6 —— 说明旧结构确实没有速度调节。

## 下一步

1. 烧录后同样测：满档短按 1 s，看是否每次都能进入“pitch 低于目标角”的滚动状态；
2. 若仍然偶尔“贴在目标角上不动”，说明 1.5° 上限不够，或该角度下静摩擦太大：先把 `speedErrorGain` 0.15→0.20，
   再考虑上限 1.5→1.8；
3. 若速度冲过目标后反复超调，把 `speedErrorGain` 降到 0.10，或加 0.3 s 的速度误差死区；
4. 稳态差 7%（9.3 vs 10）目前接受；要精确到目标速度再加带抗饱和的慢积分，但先不要加。
