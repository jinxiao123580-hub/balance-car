## 三条硬结论

1. **`N=0.8` 是稳定边界。** `N=2.0` 时速度误差一旦变大，环反向往死里拽 2° → 翻车。
   收到 0.8° 后：起步 0.96° 被截到 0.8°（仍高于破粘门槛 0.5~0.7°），反向最大也只 0.8°，拽不翻。
2. **`SP>0` = 后退，`SP<0` = 前进**（已验证，两向符号相反）。
3. **纯 P 只能"点动"，不能匀速巡航**：接近目标速度时倾角自动缩回门槛以下 → 粘住 → 稳态≈0。

## 已否证（别再重推）

| 假设/做法 | 错在哪 |
|---|---|
| 加 I 能消稳态误差 | 在静摩擦系统里变成极限环，稳态速度**反向** |
| 增益越大越好 | SV≥0.2 直接猛冲撞翻 |
| N 越大越有力 | N=2.0 就是翻车的直接原因 |
| 机械松动是对不对称的全部解释 | 紧固后方向正确率提高，但 39:1 依旧，直到 N 收到 0.8 |
| 地面坡度是全部原因 | 同一桌面、仅烧录重启，θ* 仍从 4.24 跳到 2.99 |
| 开机姿态会改写平衡点 | `pitchZero = PITCH_MOUNT_OFFSET_DEG` 是固定安装偏置 |
| `speedKp` 无在线旋钮 | **错**：`K` 一直是它（`main.cpp` L4707） |

## 还没解决

- **单腿幅度离散 6 倍**（2.8~20.5mm）：来自静摩擦破粘随机性。
- **巡航速度上不去**：`MAX_TARGET_FORWARD_SPEED=8` 是编译期常量，把 SP 锁在静摩擦主导区间；
  改到 30 需要**烧录**（用户暂不烧）。
- **编码器 pos 是否代表车体位移**：机械紧固后再没做相机对照。
